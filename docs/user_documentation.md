# TAMU Ideathon User Documentation

This guide is for organizers using the manager and admin dashboards.

## Access

- Sign in with your TAMU Google account.
- If you cannot access dashboards, ask an admin to verify your role.

## Manager Dashboard (`/manager`)

- View attendees and teams.
- Search attendees by name or team.
- Export participants and teams as CSV.
- Add, edit, and delete attendees.
- Add, edit, and delete events.

## Admin Content Dashboard (`/dashboard/*`)

Use these pages to manage year-based public content:

- Ideathons
- Sponsors and Partners
- Mentors and Judges
- FAQs
- Rules
- Activity Log

## Publishing Workflow

1. Create or update content in dashboard modules.
2. Make sure the intended ideathon year is active in Ideathons.
3. Verify the public home page reflects the year and content.

## Troubleshooting

- If exports say no data is available, confirm records exist for the correct year and content type.
- If links fail, confirm routes are loaded and restart the Rails server.
- If sign-out does not work, refresh and try again from dashboard navigation.
